# 📸 Screenshot Lifecycle Manager

> Because hundreds of screenshots seemed perfectly reasonable at the time. 😂

---

## 🌱 The Problem

I take a large number of screenshots while studying, troubleshooting, documenting projects, comparing job postings, and working with technical instructions.

These screenshots are useful in the moment, but they quickly accumulate across my:

- Windows PC
- Samsung phone
- Lenovo tablet

Manually reviewing and deleting them is repetitive, easy to forget, and surprisingly time-consuming.

---

## 🎯 Project Goal

Build a safe, cross-platform tool that helps manage screenshots automatically.

The tool should reduce digital clutter without risking the accidental loss of important files.

---

## 🛡️ Safety First

The project will begin in **read-only mode**.

Early versions will:

- Scan folders
- Count screenshots
- Display file information
- Generate reports
- Make no changes to any files

Deletion or automatic cleanup will only be added after careful testing.

No screenshots will be harmed during Version 0.1. 😄

---

## 🚧 Version 0.1 — Folder Scanner

The first version will:

- Scan one selected folder
- Count the files inside it
- List screenshot filenames
- Show the oldest screenshot
- Show the newest screenshot
- Make no changes

---

## 🗺️ Future Versions

### Version 0.2 — Age Detection

- Identify screenshots older than a selected number of days
- Display files that would qualify for cleanup
- Add a dry-run report

### Version 0.3 — Reporting

- Export results to a text or CSV report
- Record scan date and time
- Estimate storage used by screenshots

### Version 0.4 — Safe Cleanup

- Move approved screenshots to a quarantine folder
- Log every file moved
- Allow files to be restored

### Version 0.5 — Scheduling

- Run automatically each evening
- Support Windows Task Scheduler
- Explore Android automation options

### Version 1.0 — Cross-Platform Release

- Windows support
- Android workflow
- Configurable folders
- Configurable retention period
- Clear documentation and testing

---

## 🧪 Development Approach

Each feature will be built in small, testable steps:

1. Scan
2. Report
3. Test
4. Quarantine
5. Automate
6. Celebrate when it works 🎉
